# Code-for-Time-Crystals-in-Coupled-Exciton-Polariton-Condensates-

This file explains the parameters used in the numerical calculations.

The parameters used in the calculations are assumed to have the dimensions of PHz.

For instance, in Fig. 2(a), we choose P = (2×10⁻⁴, 3×10⁻⁸, 10⁻⁸, 10⁻⁴, 10⁻⁴) PHz.

The time interval is [0, 10⁶] PHz⁻¹ = [0, 10⁶] × 10⁻⁶ GHz⁻¹. Since κ₀ = 10² GHz, the rescaled time (κ₀ · t) takes values in the range [0, 10²], as shown in Fig. 2(a).

A similar analysis can be applied to Fig. 2(b), Fig. 4(a), and  Fig. 4(b).
